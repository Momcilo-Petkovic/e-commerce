# e-commerce: frontend

React 19 + Vite + Tailwind CSS single-page app for the e-commerce store.

```bash
npm install
npm run dev      # http://localhost:5173 (API requests are proxied to http://localhost:8080)
npm run build    # production build in dist/
```

See the [project README](../README.md) for the full feature list and setup instructions.
